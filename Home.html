IdeaBoard - Complete Source Code

Project Overview

IdeaBoard is a lightweight idea-sharing application where users can post and view ideas. The app features simple username-based authentication (no passwords), with admin privileges auto-assigned to the project owner.

Database: PostgreSQL with Drizzle ORM
Frontend: React + Wouter + TanStack Query
Backend: Express.js with session authentication
UI Framework: Shadcn/ui with Tailwind CSS
